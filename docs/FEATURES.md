# 功能說明

> 各功能在 web / iOS 的支援狀態請見根目錄 [README](../README.md#功能對照表)。

## 🔥 FIRE 目標計算器 (New!)
- **即時試算**: 根據歷史花費自動計算「平均月支出」與「預估年支出」。
- **參數調整**: 支援自訂「提領率 (Withdrawal Rate)」，模擬不同退休情境。
- **進度追蹤**: 視覺化呈現 FIRE 目標達成率 (Progress Bar) 與年度花費統計。

## 💳 對帳單核對
- **智能篩選**: 可依照帳戶別 (信用卡/現金) 與日期區間篩選交易紀錄。
- **快速核銷**: 互動式勾選核對，即時計算已確認金額，協助精準理財。

## 📈 投資組合分析
- **個股績效模組**: 專屬的「個股績效分析」儀表板。
- **股票交易匯入**: 支援證券戶 CSV 或 textarea 貼上匯入，採 append 模式保留歷史交易，匯入前會顯示明細與略過原因。
- **貼上格式更友善**: 台股可直接貼上手動整理後的 tab 格式交易明細；美股除了原本 CSV，也支援券商每筆交易明細的 tab 貼上格式。
- **美股日期格式判斷**: 美股交易匯入會自動判斷 `MM/DD/YYYY` 與 `YYYY/MM/DD`，若券商格式不明確，也可在匯入 popup 手動指定日期格式，檔案上傳與 textarea 貼上都會套用。
- **台股 / 美股區分**: 台股現金流與美股資料會以台股 / 美股分頁分開檢視損益；美股支援每筆券商交易明細匯入，舊版已平倉損益 CSV 已封存，僅保留明確補救匯入入口與既有資料相容。
- **美股現金流摘要**: 美股分頁會列出股息、利息與匯款淨額，方便把交易損益與現金流分開檢查。
- **美股匯率換算**: 美股總損益預設以 `(USD)` 顯示，可用右上角按鈕切換為依今日美元匯率換算的台幣金額。
- **美股精度**: 美股損益與交易金額保留小數點後兩位，避免已實現損益被整數四捨五入。
- **持倉快照版本**: 可用手動欄位輸入「市場、股票名稱、現價、股數」建立每月持倉版本，並依台股 / 美股分頁瀏覽各版本內容。
- **前次持倉帶入**: 匯入持倉快照時，可依目前所在的台股 / 美股分頁，一鍵帶入上一次同市場持倉後再微調。
- **快照月份數字化**: 持倉快照月份改為固定 `YYYY-MM` 格式，避免不同瀏覽器出現英文月份。
- **最新估值試算**: 持倉快照輸入可抓取最新股價輔助填入現價；台股會優先使用較新的市場價、失敗時才回退收盤價，並支援上櫃股票名稱 / 代號解析；快照版本內容可另外試算最新估值與差異，且不會改寫原本快照。
- **持倉單價顯示**: 持倉快照版本中的快照價與最新價最多顯示到小數第 2 位，若尾數為 0 會自動省略。
- **市場範圍清空**: 股票交易清空會依目前市場分頁執行，刪除美股交易不會影響台股資料。
- **損益追蹤**: 結合股票交易與選定持倉快照，計算個股總損益、目前市值、股息與報酬率 (ROI)；若有股票質押，會另外顯示扣除質押後淨損益與估算利息。
- **搜尋、區間與圖表**: 個股損益表支援名稱/代號搜尋與日期區間績效篩選，並以長條圖快速查看損益影響最大的股票；區間模式只計算日期內交易、股息與費用，不納入持倉快照市值。
- **交易明細彈窗**: 點擊個股後可開啟 popup 檢視逐筆交易、股數、價格與原始說明。
- **排行榜完整檢視**: 賺最多 / 虧最多卡片可開啟完整排行榜 popup，且標題列與關閉按鈕會固定在頂部，方便捲動瀏覽。
- **配息現金流**: 視覺化呈現每月/年度股息收入，掌握被動收入趨勢。

## 📊 財務視覺化
- **年度資產趨勢**: 互動式 Area Chart，支援跨年份比較；月份列表中未紀錄資產的月份會顯示 0，但圖表仍保留 12 個月 x 軸並以空值略過未紀錄點，避免線圖誤判為資產歸零。
- **年度資產增長**: 以本年度第一筆與最後一筆實際資產紀錄的淨值差額計算，避免負債或未紀錄月份影響年度成長判讀。
- **年度高低點**: 年度最高與年度最低只會比較有實際資產紀錄且金額大於 0 的月份；年度增長比例會以 📈 / 📉 標示上升或下跌趨勢。
- **收支結構**: 自動統計花費類別，提供 Top 5 開銷分析。
- **區間統計**: 可用三段式檢視指定區間的現金流、資產負債變化與財務推估；資產變化會納入期初 / 期末負債，避免股票質押等借款造成資產膨脹誤判。
- **綜合損益指標**: 獨家綜合評分算法，結合「收入成長」與「資產累積」雙重指標。

## 🧾 負債與質押管理
- **負債快照**: 可在指定日期記錄股票質押、貸款或其他負債，並自動納入淨資產計算。
- **未還款延續**: 月份明細會以截至該月月底的有效負債顯示，若本月沒有新快照，會沿用前期未還款負債並標示來源日期。
- **負債類別**: 新增負債可選股票質押、信用貸款、房貸、車貸、信用卡、分期付款、親友借款與其他類別。
- **股票質押欄位**: 選擇股票質押時會自動帶入負債名稱，並可逐列記錄股票代號/名稱、股數與利率。
- **台股質押判斷**: 股票質押可辨識 `00981A`、`00679B` 這類數字加英文字尾的台股代號，確保個股績效中的台股質押負債分攤正確。
- **質押利息估算**: 股票質押輸入利率後，會即時計算預估月息 / 年息，並同步顯示在負債明細與個股績效卡片。
- **利率調整事件**: 若券商調整股票質押利率，可在負債異動中新增「利率調整」，直接指定調整對象並更新各檔質押股票的新利率，不需重建本金快照。
- **按日期切分月息**: 同一月份若中途調整股票質押利率，本月預估利息會依調整生效日期自動分段重算，最新負債快照與個股績效也會同步套用。
- **機構 / 帳戶選擇**: 新增負債時會依日期列出同月或之前最近一次資產紀錄中的帳戶，也可手動輸入。
- **負債異動明細**: 支援借款增加、還本金、利息、手續費、擔保品與利率調整異動，適合追蹤同月多次質押、追加擔保品或券商調整質押條件；月份明細中保留異動列表但移除上方摘要卡，降低畫面干擾。
- **同月統整**: 資產、負債、收入、花費與備忘錄會以月份聚合檢視，同月不同日期的紀錄不會被拆散。

## 💰 全方位資產管理
- **多維度紀錄**: 整合資產總額 (固定/浮動)、負債、月收入、月結餘與備忘錄。
- **快速新增選單**: 新增紀錄入口依常用程度排列，支援新增資產、收入、負債、匯出備份與匯入資料。
- **收入日期化**: 新增收入改用完整日期選單，並在收入明細與匯入差異中保留日期資訊。
- **智慧匯入**: 
  - **MOZE 記帳**: 支援 CSV 花費匯入與自動分類 (Local / Dropbox)。
  - **完整備份 v2**: JSON 備份包含資產、收入、花費、備忘錄、負債、負債異動、個股交易明細與持倉庫存版本，匯出的檔案可直接重新匯入還原。
  - **向下相容**: 新版備份含格式名稱、版本與匯出時間；匯入端仍支援既有的舊版平面 JSON 備份。
  - **差異預覽**: JSON 備份與花費 CSV 匯入前，會先顯示「新增 / 刪除 / 修改」差異明細，個股交易與持倉庫存也會列出變更內容。
  - **同資料還原**: JSON 備份即使與目前資料完全一致，仍可確認覆蓋還原；花費 CSV 沒有差異時則會直接略過。
  - **證券戶交易**: 支援特定格式的台股交易紀錄匯入 (CSV 或 tab 貼上，含買入/賣出/股息/入金) 與美股每筆交易明細匯入 (CSV 或 tab 貼上，含買進/賣出/股息/利息/匯款)，可從檔案或 textarea 匯入並預覽明細；台股質押借款列會自動略過以避免和負債重複計算，美股已平倉損益 v1 匯入已封存，只保留手動補救入口。
- **智能匯率快取**: 
  - 自動記憶當月外幣匯率，跨功能 (收入/資產) 共享，減少重複輸入。
- **年度統計卡片**: 快速檢視年度資產增長率、平均月收與資產高點。

## ☁️ 企業級雲端架構
- **Google 登入**: 整合 Firebase Authentication，安全便利。
- **即時同步**: 資料即時寫入 Firestore，多裝置無縫接軌。
- **智能分塊技術**: 針對大量歷史數據實作 Chunking 機制，突破 Firestore 單一文件限制，確保極速載入。
