# 極簡貓資產 (CatLog) 📊

**極簡貓資產** 是一個現代化、介面精美的個人資產與投資組合追蹤應用程式。專為重視數據分析的投資者設計，提供直觀的資產淨值趨勢、負債與質押追蹤、月度收支管理，以及深度的個股績效分析。

> 📖 **詳細規劃請見**：[專案計劃書 (Project Plan)](PROJECT_PLAN.md)

## ✨ 特色功能

### 🔥 FIRE 目標計算器 (New!)
- **即時試算**: 根據歷史花費自動計算「平均月支出」與「預估年支出」。
- **參數調整**: 支援自訂「提領率 (Withdrawal Rate)」，模擬不同退休情境。
- **進度追蹤**: 視覺化呈現 FIRE 目標達成率 (Progress Bar) 與年度花費統計。

### 💳 對帳單核對
- **智能篩選**: 可依照帳戶別 (信用卡/現金) 與日期區間篩選交易紀錄。
- **快速核銷**: 互動式勾選核對，即時計算已確認金額，協助精準理財。

### 📈 投資組合分析
- **個股績效模組**: 專屬的「個股績效分析」儀表板。
- **股票交易匯入**: 支援證券戶 CSV 或 textarea 貼上匯入，採 append 模式保留歷史交易，匯入前會顯示明細與略過原因。
- **台股 / 美股區分**: 台股現金流與美股已平倉損益 CSV 會自動辨識格式，並以台股 / 美股分頁分開檢視損益。
- **美股匯率換算**: 美股總損益預設以 `(USD)` 顯示，可用右上角按鈕切換為依今日美元匯率換算的台幣金額。
- **美股精度**: 美股損益與交易金額保留小數點後兩位，避免已實現損益被整數四捨五入。
- **持倉快照版本**: 可用手動欄位輸入「市場、股票名稱、現價、股數」建立每月持倉版本，並依台股 / 美股分頁瀏覽各版本內容。
- **市場範圍清空**: 股票交易清空會依目前市場分頁執行，刪除美股交易不會影響台股資料。
- **損益追蹤**: 結合股票交易與選定持倉快照，計算個股總損益、目前市值、股息與報酬率 (ROI)。
- **搜尋與圖表**: 個股損益表支援名稱/代號搜尋，並以長條圖快速查看損益影響最大的股票。
- **配息現金流**: 視覺化呈現每月/年度股息收入，掌握被動收入趨勢。

### 📊 財務視覺化
- **年度資產趨勢**: 互動式 Area Chart，支援跨年份比較。
- **收支結構**: 自動統計花費類別，提供 Top 5 開銷分析。
- **綜合損益指標**: 獨家綜合評分算法，結合「收入成長」與「資產累積」雙重指標。

### 🧾 負債與質押管理
- **負債快照**: 可在指定日期記錄股票質押、貸款或其他負債，並自動納入淨資產計算。
- **負債異動明細**: 支援借款增加、還本金、利息、手續費與擔保品異動，適合追蹤同月多次質押或追加擔保品。
- **同月統整**: 資產、負債、收入、花費與備忘錄會以月份聚合檢視，同月不同日期的紀錄不會被拆散。

### 💰 全方位資產管理
- **多維度紀錄**: 整合資產總額 (固定/浮動)、負債、月收入、月結餘與備忘錄。
- **快速新增選單**: 新增紀錄入口依常用程度排列，支援新增資產、收入、負債、匯出備份與匯入資料。
- **收入日期化**: 新增收入改用完整日期選單，並在收入明細與匯入差異中保留日期資訊。
- **智慧匯入**: 
  - **MOZE 記帳**: 支援 CSV 花費匯入與自動分類 (Local / Dropbox)。
  - **差異預覽**: JSON 備份與花費 CSV 匯入前，會先顯示「新增 / 刪除 / 修改」差異明細，包含資產、收入、花費、備忘錄、負債與負債異動。
  - **只在有變更時匯入**: 若匯入內容與目前資料完全一致，系統會直接略過，不再覆蓋。
  - **證券戶交易**: 支援特定格式的台股 CSV 交易紀錄匯入 (買入/賣出/股息/入金)，以及美股已平倉損益 CSV 匯入，可從檔案或 textarea 匯入並預覽明細。
- **智能匯率快取**: 
  - 自動記憶當月外幣匯率，跨功能 (收入/資產) 共享，減少重複輸入。
- **年度統計卡片**: 快速檢視年度資產增長率、平均月收與資產高點。

### ☁️ 企業級雲端架構
- **Google 登入**: 整合 Firebase Authentication，安全便利。
- **即時同步**: 資料即時寫入 Firestore，多裝置無縫接軌。
- **智能分塊技術**: 針對大量歷史數據實作 Chunking 機制，突破 Firestore 單一文件限制，確保極速載入。

## 🚀 快速開始

### 1. 安裝依賴
```bash
npm install
```

### 2. 設定環境變數
請在專案根目錄建立 `.env` 檔案，並填入 Firebase 設定：

```env
VITE_FIREBASE_API_KEY=your_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
VITE_FIREBASE_PROJECT_ID=your_project_id
VITE_FIREBASE_STORAGE_BUCKET=your_storage_bucket
VITE_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
VITE_FIREBASE_APP_ID=your_app_id
VITE_DROPBOX_APP_KEY=your_dropbox_app_key (Optional: for Dropbox Import)
```

### 3. 啟動開發伺服器
```bash
npm run dev
```
開啟瀏覽器訪問 `http://localhost:5173`。

### 4. 執行測試
支援完整的單元測試與整合測試：

```bash
# 執行所有測試
npm test

# UI 測試模式
npm run test:ui
```

### 5. CI/CD
本專案已整合 GitHub Actions，在 `main` 分支的 Push 與 PR 事件將自動觸發 CI 流程，執行所有測試案例以確保程式碼品質。
